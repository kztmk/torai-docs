# Glossary

## API Key

A key that identifies your application to the X API.

## API Key Secret

Secret information used together with the API Key.

## Access Token

A token used to call the API with the permissions of an X account.

## Access Token Secret

Secret information used together with the Access Token.

## Apps Script

Google's script execution environment. Torai uses it to process posts in Google Sheets and run scheduled X Marketing data collection.

## Trigger

A mechanism that runs Apps Script on a schedule.

## X Marketing

Torai features for managing reactions to your posts and analyzing your own post information and engagement. It includes the Response Inbox, Responder CRM, and Post Analytics.

## Engagement

Actions involving a post, such as likes, replies, reposts, quotes, and clicks. Torai displays only values returned by the X API.

## Impressions

The number of times a post was displayed. Torai shows **—** when the X API does not provide this value.

## Response Inbox

A page that organizes reactions to your posts so you can review unread items, high-priority responders, and reaction types.

## Responder CRM

A page for managing CRM stages, custom tags, and notes for people who reacted to your posts. CRM stands for Customer Relationship Management.

## Post Analytics

A feature that displays impressions, engagement, daily trends, and the latest metrics for your own posts within the tracking period.

## Daily snapshot

A record of post metrics captured for a particular day and stored in Google Sheets. These records provide the data for the daily trend chart.

## Lead score

A Torai score used as a guideline for response priority based on reaction history. It does not guarantee a person's intent or interest.
