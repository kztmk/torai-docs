# Check X API Pay-per-use Pricing

The current version assumes that you are billed according to your X API usage.

Check usage and billing in the X Developer Console for both write operations such as publishing and read operations used by X Marketing to retrieve your posts, engagement metrics, and responders.

## Where Torai uses the X API

| Torai feature | Main API usage |
| --- | --- |
| Standard, scheduled, and thread posts | Write data to X |
| Response Inbox and Responder CRM | Read your posts, liking users, mentions, and replies |
| Post Analytics | Read your post information, public metrics, and any engagement metrics available to the account |

Responder Collection and Post Analytics can be turned on or off independently. When either feature is on, X Marketing normally collects data once per day.

## What to check

- You can sign in to the X Developer Console
- You have a Project / App for each X account that will post
- Your credits or billing settings are configured
- You can view usage on the Usage page
- You have checked prices and limits for both publishing and data reads
- You have reviewed the tracking period, number of posts, responder limit, and monthly budget setting in X Marketing

:::caution
The amount displayed in Torai's X Marketing screen is an estimate based on resources read for analytics. It does not include write charges for posts, replies, or threads. Treat the X Developer Console as the source of truth for actual usage and billing.
:::

## Using multiple accounts

When you manage multiple X accounts with Torai, obtain a complete set of API keys for each X account.

Name and store the credentials so that you can identify which X account each set belongs to.

:::caution
As a security measure, Torai encrypts all information related to your X accounts and stores it in your own Google Sheet.

Torai cannot display these credentials again after they have been saved.
:::
