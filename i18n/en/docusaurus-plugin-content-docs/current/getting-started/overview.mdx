# Before You Start

Prepare the following before using Torai.

## Requirements

- A Torai subscription (credit card)
- An X account to post from
- A Google Account
- A Gemini API key (if you want to create post or reply drafts with AI)
- A Discord account (if you want to receive Torai posting results)

## Potential costs

- A monthly Torai subscription in USD
- Pay-per-use X API charges for publishing and reading posts, engagement, and responders
- Gemini API usage charges

## In this section

- What to check before starting a subscription
- How X API pay-per-use pricing works
- The Google accounts and permissions you need
- Important points when managing multiple X accounts
- X Marketing collection switches and the monthly budget setting

Publishing and X Marketing use the same Google Sheet, Apps Script deployment, and four X API credentials. You can turn scheduled X Marketing collection on or off for each feature.
