# If You Are Concerned About API Usage or Charges

External API costs may be charged separately from your Torai subscription.

## X API

Check Usage and billing settings in the X Developer Console.

Before scheduling a large number of posts or threads, check the number of planned posts and your current usage.

If you use X Marketing, compare **Estimated this month** at the top of the screen with Usage in the X Developer Console.

- **Publishing charges are increasing**: Review scheduled posts, replies, and threads.
- **Read charges are increasing**: Reduce the tracking period, posts per account, or responders per post.
- **You do not need responder data**: Turn off **Responder Collection**.
- **You do not need post metrics**: Turn off **Post Analytics**.
- **Stop all scheduled X Marketing reads**: Turn both switches off.

:::caution
Torai's estimate does not include publishing write charges, and its monthly budget setting is not the X Developer Console billing cap. Confirm actual charges in the X Developer Console.
:::

## Gemini API

Check usage and billing settings in the relevant Google management console.

Before generating a large number of AI post drafts, check your usage limit and billing settings.

**Create an AI reply draft** in the Response Inbox also makes one Gemini API request. Each regeneration adds usage.
