# Xポスト検索・X記事検索

条件を入力するだけで、X（旧Twitter）の高度な検索URLを組み立て、検索結果画面を別タブで開くツールです。虎威のサーバーには何も送信されず、すべてブラウザ内で完結します。

APIキーの登録は不要です。

## Xポスト検索

左側メニューの「Tools」から「Xポスト検索」を開きます。

![Xポスト検索](/img/torai-tools/ja/search_post01.jpeg)

入力できる項目は次のとおりです。未入力の項目は検索条件に含まれません（少なくとも1項目は入力が必要です）。

| 分類                       | 項目                                                                                                                   |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| ユーザー                   | 投稿者（from）、返信先（to）                                                                                           |
| キーワード                 | キーワード（AND/OR切り替え可）、完全一致フレーズ、除外キーワード、リストID                                             |
| 期間                       | 開始日・開始時刻、終了日・終了時刻                                                                                     |
| メディア・エンゲージメント | メディアの種類、最小いいね数、最小リポスト数、最小リプライ数                                                           |
| フィルター                 | 引用ポスト、フォロー中のアカウントのみ、認証済みアカウント（それぞれ「どちらでも」「これのみ」「これを除外」から選択） |
| その他                     | 特殊な投稿種別（Spaces / ニュース）、言語、リプライの扱い                                                              |

条件を入力して「Xで検索」をクリックすると、検索結果が新しいタブで開きます。

![Xポスト検索](/img/torai-tools/ja/search_post02.jpeg)

## X記事検索

同じく「Tools」から「X記事検索」を開きます。X記事（Articles）に絞り込んだ検索を行います。

![X記事検索](/img/torai-tools/ja/search_post03.jpeg)

| 項目                             | 内容                                             |
| -------------------------------- | ------------------------------------------------ |
| 投稿者                           | from指定でユーザーを絞り込み                     |
| 期間                             | 開始日・開始時刻、終了日・終了時刻               |
| 最小いいね・リポスト・リプライ数 | それぞれ数値で下限を指定                         |
| フォロー中のアカウントのみ       | 「どちらでも」「これのみ」「これを除外」から選択 |

![X記事検索](/img/torai-tools/ja/search_post04.jpeg)

## 入力値の確認について

各項目には入力してよい値の形式チェック（ユーザー名の形式、日付の形式、0以上の整数かどうかなど）があります。形式が正しくない場合はエラーが表示され、検索は実行されません。

:::caution
Xの検索演算子は、X側の仕様変更により予告なく変更・廃止される場合があります。特定の条件で検索結果が想定と異なる、または「結果なし」になる場合は、X側の仕様が変更された可能性があります。
:::
