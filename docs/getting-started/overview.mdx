# 利用前チェック

虎威を利用する前に、以下を準備します。

## 必要なもの

- 虎威のサブスクリプション契約（クレジットカード・銀行振り込み）
- 投稿に使用する X アカウント
- Google アカウント
- Gemini API Key（AIでポストや返信案を作成する場合）
- Discode アカウント（虎威の投稿結果を受信する場合）

## 費用が発生するもの

- 虎威の月額または年額サブスクリプション
- X API の従量課金（投稿、投稿情報・エンゲージメント・反応者の取得）
- Gemini API の利用量に応じた費用（無料枠内ですと費用は不要）

## この章で説明すること

- サブスクリプション開始前に確認すること
- X API 従量課金の考え方
- Google 側で準備するアカウントと権限
- 複数 X アカウント運用時の注意点
- Xマーケティングの取得スイッチと予算上限

投稿作成と自動投稿だけを使う場合でも、Xマーケティングを使う場合でも、同じGoogle Sheet、Apps Script、X APIキー4種を利用します。Xマーケティングによる定期取得は、機能ごとにON/OFFできます。
