# 用語集

## API Key

X API でアプリを識別するためのキーです。

## API Key Secret

API Key と組み合わせて使う秘密情報です。

## Access Token

X アカウントの権限で API を実行するためのトークンです。

## Access Token Secret

Access Token と組み合わせて使う秘密情報です。

## Apps Script

Google が提供するスクリプト実行環境です。虎威ではGoogle Sheet上の投稿処理と、Xマーケティングの定期データ取得に使います。

## トリガー

Apps Script を定期的に実行する仕組みです。

## Xマーケティング

自分の投稿に対する反応を管理し、自分の投稿情報とエンゲージメントを分析する虎威の機能です。対応インボックス、反応者CRM、投稿分析で構成されます。

## エンゲージメント

投稿に対するいいね、返信、リポスト、引用、クリックなどの反応です。虎威はX APIから取得できた値だけを表示します。

## 表示回数（インプレッション）

投稿が表示された回数です。X APIから取得できない場合、虎威では「—」と表示します。

## 対応インボックス

自分の投稿への反応を一覧化し、未対応、高優先度、反応の種類などから確認する画面です。

## 反応者CRM

反応したユーザーの対応ステージ、自由タグ、メモを管理する画面です。CRMはCustomer Relationship Managementの略です。

## 投稿分析

追跡期間内にある自分の投稿について、表示回数、エンゲージメント、日別推移、投稿別の最新値を確認する機能です。

## 日別スナップショット

1日ごとの取得時点における投稿指標をGoogle Sheetへ保存した記録です。日別推移チャートの元データになります。

## リードスコア

反応回数などから、対応順を考えるために虎威が算出する目安です。相手の意図や関心を保証するものではありません。

## Tools

左側メニューにある機能グループです。AI画像生成、週次投稿生成、Xポスト検索、X記事検索などが含まれます。

## AI画像生成

Agnes AI（BYOK）を使い、プロンプトからXポスト用の画像を生成してGoogleドライブへ保存する虎威の機能です。

## Agnes AI

虎威が画像生成に利用する外部のマルチモーダルAI APIです。虎威が提供するサービスではなく、料金・無料枠・利用規約はAgnes AI側の情報に従います。

## 週次投稿生成

Gemini（BYOK）を使い、1週間分のXポスト案をテーマ・曜日・時間帯・カテゴリの条件からまとめて生成する虎威の機能です。

## BYOK

Bring Your Own Keyの略です。虎威に登録した外部AIサービス（Gemini、Agnes AIなど）のAPIキーをご自身のものとして扱い、虎威側はそのキーを保管・仲介するだけで、費用や利用規約の遵守はユーザーの責任となる仕組みです。
