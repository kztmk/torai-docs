# 制限と注意事項

虎威は複数の外部サービスを利用するため、それぞれの制限を確認してください。

## Google

- Apps Script の実行時間
- 外部アクセス回数
- トリガー数
- Google ドライブ容量

自動投稿とXマーケティングは別のトリガーを使用します。Xマーケティングでは、「反応者取得」または「投稿分析」のどちらかがONの場合に日次トリガーを作成し、両方をOFFにすると削除します。

## X

- API 利用量
- 投稿、リプライ、スレッド投稿に関する書き込み制限
- 自分の投稿情報、エンゲージメント、反応者に関する読み取り制限
- メディアアップロードに関する制限
- 従量課金と Usage

取得可能な指標は、Xアカウントの権限、投稿の種類、取得期間、X側の仕様によって異なります。虎威は取得できない値を推測せず「—」で表示します。

## Gemini

- API 利用量
- 課金設定
- 生成結果の確認

Gemini APIは、AI投稿案と対応インボックスのAI返信案で使用します。再生成するたびに追加のAPI利用量が発生します。

## 虎威

- サブスクリプション状態
- 登録可能なアカウント数
- 利用できる機能の範囲
- 反応者データはGoogle Sheetに最新2,000件まで保存
- 投稿別の最新指標は最大2,000件まで保存
- 画面へ返す反応者データと投稿分析データはそれぞれ最大1,000件
- 日別スナップショットは最大20,000件、約32日分

保存上限や保持期間を超えた古いXマーケティングデータは、次回の取得・保存時に整理されます。
