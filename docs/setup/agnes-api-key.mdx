# Agnes AI API Key の取得

虎威の「AI画像生成」を使う場合は、Agnes AIのサイトでAPI Keyを取得します。

Agnes AIは、テキスト・画像・動画生成に対応したマルチモーダルAI APIを無料/従量制で提供する外部サービスです。虎威は取得したAPIキーをご自身のもの（BYOK：Bring Your Own Key）として扱い、画像生成にのみ使用します。

:::caution
Agnes AIは虎威が提供するサービスではありません。料金、無料枠、利用規約、生成された画像の著作権や利用範囲については、必ずAgnes AI側の最新情報をご自身で確認してください。
:::

## APIキー取得方法

### 1. Agnes AIのサイトへアクセス

[Agnes AI](https://agnes-ai.com/) へアクセスし、アカウントを作成してAPIキーを発行します。

### 2. APIキーをコピー

発行されたAPIキーをコピーします。

## 虎威への登録

取得したキーは、虎威の「プロフィール > APIキー」にある「Agnes AI API Key」欄に入力して保存します。

保存すると、GAS連携（Googleスプレッドシート・Apps Script）が完了している場合、APIキーは虎威のApps Script側にも自動的に同期されます。画像生成のリクエストはApps Script経由で行われるため、この同期が完了していないと画像生成時に「Agnes AI APIキーが設定されていません」というエラーになります。

:::info
Agnes AI API Keyを保存する前に、先に [Google スプレッドシートの設定](./apps-script-deploy-link) を完了し、GAS連携を有効にしておいてください。
:::
