# Gemini API Key の取得

虎威のAI投稿案作成と、対応インボックスの「AIで返信案を作成」を使う場合は、Google AI StudioでGemini API Keyを取得します。

Googleが提供するGeminiは、無料枠の範囲内で利用できます。Gemini APIは、アプリからAIを直接利用するためのインターフェースです。

## Geminiの利用枠

虎威では、GeminiのFlash-Lite系最新モデルを指す `gemini-flash-lite-latest` を使用します。このエイリアスが指すモデルは、Googleにより更新される場合があります。

利用できる無料枠やリクエスト上限は、使用中のモデル、プロジェクト、利用階層によって異なります。Google AI Studioで、自分のプロジェクトに適用されている現在の上限を確認してください。

:::caution
Gemini API の料金や無料枠は変更される可能性があります。利用前に Google 側の最新情報を確認してください。
:::

## APIキー取得方法

### 1. Google AI Studioへアクセス

[Google AI Studio](https://aistudio.google.com)へアクセスします。「Get started」をクリックします。
Googleへログインしていない場合には、ログインが必要です。

![Google AI Studio](/img/getting-start/gemini_access.jpg)

### 2. キーをクリック

左下の「カギ」ボタンをクリックします。

![Google AI Studio](/img/getting-start/gemini_try_key.jpg)

### 3. キーが表示

キーが表示されます。無料枠になっているのを確認してください。

![Google AI Studio](/img/getting-start/gemini_get_key.jpg)

### 4. キーをコピー

キーをクリックするとキーの詳細が表示されます。

![Google AI Studio](/img/getting-start/gemini_copy_key.jpg)

以上でGemini APIキーの取得は完了です。

取得したキーは、虎威の「プロフィール > APIキー」で登録してテストします。未登録の場合、対応インボックスでAI返信案を作成しようとすると、Gemini APIキーが未登録であることを案内します。
