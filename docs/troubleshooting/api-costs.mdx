# API 利用量や課金が不安なとき

外部 API の費用は虎威のサブスクリプションとは別に発生する場合があります。

## X API

X Developer Console で Usage と課金設定を確認します。

大量の予約投稿やスレッド投稿を実行する前に、投稿予定数と利用量を確認してください。

Xマーケティングを使っている場合は、画面上部の「今月の推定費用」とX Developer ConsoleのUsageを比較します。

- **投稿費用が増えている**: 予約投稿、リプライ、スレッド投稿の件数を確認します。
- **データ読み取り費用が増えている**: Xマーケティングの追跡期間、取得投稿数、反応者取得上限を小さくします。
- **反応者データが不要**: 「反応者取得」をOFFにします。
- **投稿分析が不要**: 「投稿分析」をOFFにします。
- **Xマーケティングの定期読み取りをすべて停止**: 両方のスイッチをOFFにします。

:::caution
虎威の推定費用には投稿の書き込み費用が含まれません。また、虎威の月間予算上限はX Developer Consoleの請求上限ではありません。実際の料金はX Developer Consoleで確認してください。
:::

## Gemini API

Google 側の管理画面で利用量と課金設定を確認します。

AI 投稿案を大量に生成する前に、利用量の上限や請求設定を確認してください。

対応インボックスの「AIで返信案を作成」もGemini APIを1回呼び出します。返信案を再作成するたびに追加の利用量が発生します。
