# V3.2リリース

虎威　Version 3.2をリリースしました。

- Agnes AIを使用しての無料で画像生成
- 1週間分の投稿（予約時刻込み）をGeminiで作成
- Xの投稿・記事を検索する機能を追加

## Agnes AIを使用しての画像生成

[Agnes AI](https://agnes-ai.com/)は、クレジットカード登録不要で無料のAPIでの画像生成を提供している企業です。無料ですが十分な機能を持ち、制限はRPM（1分間の要求）だけです。

この画像生成機能を「虎威」へ組み込みました。作成した画像は使用する場合にはGoogleドライブへ保存します。

左側メニュー　→ AI画像生成で使用できます。

![AI画像生成](/img/torai-tools/ja/image_gene01.jpeg)

または、ポスト作成フォームから画像生成し、投稿へ追加することもできます。

![投稿作成フォームでAI画像生成](/img/torai-tools/ja/image_gene02.jpeg)

詳しくは、

- [マニュアル：Agnes AIでAPIキー取得](/docs/setup/agnes-api-key)
- [マニュアル：AI画像生成](/docs/usage/ai-image-generator)

いろいろなパラメーターを組み合わせてXの投稿、記事を検索する機能を追加しました。

Xの検索機能を使用しますので費用は不要です。

![Xのポスト検索](/img/torai-tools/ja/search_post01.jpeg)

[マニュアル：Xポスト検索・X記事検索](/docs/usage/x-search-tools)
